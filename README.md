# HR-Analytics-Dashboard-Power-Bi

🇧🇷 Português

Este projeto apresenta um Dashboard de Recursos Humanos desenvolvido no Power BI, criado para transformar dados de colaboradores em informações visuais para análise e tomada de decisão.

O dashboard permite acompanhar indicadores como total de funcionários, funcionários ativos, quantidade e taxa de attrition, idade média e experiência média, além de analisar o turnover por departamento, faixa salarial, cargo, nível de satisfação, gênero e experiência profissional.

O projeto foi desenvolvido utilizando Power BI, Power Query e DAX, passando pelas etapas de preparação dos dados, criação de métricas e desenvolvimento das visualizações interativas.

A proposta foi criar uma visão gerencial simples e intuitiva, permitindo identificar padrões de attrition e entender melhor a composição da força de trabalho.

🇺🇸 English

This project presents an HR Analytics Dashboard developed in Power BI, designed to transform employee data into visual insights to support analysis and decision-making.

The dashboard provides an overview of key HR indicators such as total employees, active employees, attrition count, attrition rate, average age, and average experience, while also allowing analysis of attrition by department, salary range, job role, satisfaction level, gender, and professional experience.

The project was developed using Power BI, Power Query, and DAX, covering the main stages of data preparation, metric development, and interactive data visualization.

The main goal was to create a simple and intuitive management dashboard that helps identify attrition patterns and provides a better understanding of the organization's workforce.
